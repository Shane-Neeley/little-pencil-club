# Little Pencil Club

[Open Little Pencil Club](https://little-pencil-club.fort-rock.chatgpt.site/#draw/little-fox) to start Little fox on paper. Choose from 32 lessons, or switch to Trace on screen or Blank canvas. Progress, Sketchbook drawings, and PNG export stay on your device.

## Run the game locally

From the checkout, start a static server with Python 3, then open [Little fox](http://127.0.0.1:8473/#draw/little-fox).

```sh
python3 -m http.server 8473 --bind 127.0.0.1 --directory dist
```
